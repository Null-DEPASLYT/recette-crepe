# Recette de crêpes

## 1. Préparation de la pâte

Dans un saladier, mélangez :

- la farine,
- le sel,
- le sucre en poudre.

Creusez ensuite un puits pour y casser les œufs.

Mélangez en effectuant des cercles du centre vers l’extérieur.

Versez ensuite le lait petit à petit, puis ajoutez le sucre vanillé.

Laissez reposer la pâte pendant **30 minutes**.

---

## 2. Cuisson des crêpes

Avec un coton, badigeonnez d’huile le fond de votre crêpière et faites-la chauffer à feu vif.

Une fois bien chaude :

1. Versez une louche de pâte.
2. Laissez cuire environ **3 minutes** de chaque côté.

Procédez ainsi jusqu’à épuisement de la pâte.

---

## 3. Conservation des crêpes

Empilez les crêpes sur une assiette.

Vous pouvez les recouvrir d’un torchon propre afin de les conserver au chaud.
